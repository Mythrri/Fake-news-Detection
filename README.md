# Fake News Detection 📰

A simple Machine Learning project to detect Fake vs Real news using TF-IDF and Logistic Regression.

## How it works
- Uses TF-IDF Vectorizer to convert text to numbers
- Logistic Regression model to classify news as FAKE or REAL
- Built with Streamlit for live web app

## Files
- app.py - Main application
- requirements.txt - Dependencies
- README.md - Project info
